# CapCut AI Lab · Page 3 Demo

Mobile interaction prototype based on the supplied Figma Page 3 design.

- Shared light 9:41 status bar on every screen; no Dynamic Island.
- Full-width mobile layout, safe-area support and bottom-anchored controls.
- Swipeable capability cards and the reference upload/generation flow.
- All images and icons are from the supplied design; no external icon library.

AI generation and uploads are simulated. This prototype does not call an AI service.

Open `index.html`, or serve this directory as a static site. GitHub Pages: `main` branch, `/ (root)`.
